# Truthcoin App v0.1.1

**The app no longer spends from your eCash wallet.** Deposits from eCash are made in BitWindow, to the address the
app gives.

## Changed

- **Deposit** on Home now shows this wallet's deposit address (`s13_…`, with a QR code and Copy) and where it goes in
  BitWindow: **Sidechains › Create Deposits**, pick Truthcoin, paste it into **Sidechain Deposit Address**, then the
  amount and fee (in eCash). v0.1.0 made the deposit itself, through the enforcer's wallet, which has no login: so
  the app could spend your eCash. It no longer can. It asks the enforcer only where its chain is, and, when the
  enforcer is on the same computer, for an address to withdraw to.
- **eCash on another computer:** the README and the Setup screen now recommend an SSH tunnel
  (`ssh -N -L 50051:127.0.0.1:50051 you@that-computer`), so the enforcer stays closed to the network and the
  connection is encrypted. The app then finds it at its default address. The warnings say what an open enforcer
  risks: anyone who can reach it can spend its wallet.
- **Empty amount fields no longer look filled.** On macOS the deposit's "100,000" example read as a typed amount.
  Amount fields have no example now, examples elsewhere are dimmed and italic, and the messages name the missing
  field.

## Known limits

As in v0.1.0 (its notes): the node has no RPC login and stores its seed unencrypted; trades go through with the next
Truthcoin block; a withdrawal waits for eCash miners to approve its bundle; the Mac app isn't notarised.

## Verify

`SHA256SUMS` and the tag `v0.1.1` are signed with the release key in the README; each package has a GitHub build
attestation, and the Linux program and `.deb` rebuild byte for byte from the tag. See
[VERIFY.md](https://github.com/truthcoinapp/truthcoin-app/blob/v0.1.1/VERIFY.md).
