# Truthcoin App v0.1.4

**For Truthcoin 0.20, L2L's new node, which changes the chain's rules.**

L2L released its Truthcoin node v0.20.0 on 8 October 2026. It changes the rules the chain follows (L2L calls it a
hard fork). This version of the app runs v0.20.0, and only that version.

## When you update

1. **The app asks to install the new node.** It downloads about 56 MB from L2L's GitHub release and, as before, keeps
   the download only if its SHA-256 is the one pinned in this app.
2. **The old chain and wallet are moved aside, not deleted.** 0.20 can't read what 0.19 wrote. Before 0.20 first
   starts, the app moves 0.19's files into `node/set-aside-0.19/` in its data folder. The new node then syncs the
   chain from the start.
3. **Make a wallet, or type your recovery words again.** 0.20 turns the words into keys in a different way, so the
   same words give new addresses. Coins you held with 0.19 don't show in this app. The app's records of the old
   wallet (its trades, deposits and withdrawals) go aside with it, and trades a phone left for you to confirm are
   dropped.

**Obliterate** removes the set-aside folder with the rest of Truthcoin's data, after you tick that you have your
recovery words. It removes the old node program along with the new one.

Settings › Advanced no longer has a ZMQ port, because 0.20 has none.

From v0.1.3 on, the Mac app and the AppImage offer this update themselves. For the `.deb`, download it from this page.

## Known limits

As in v0.1.0 (its notes): the node has no RPC login and stores its seed unencrypted; trades go through with the next
Truthcoin block; a withdrawal waits for eCash miners to approve its bundle; the Mac app isn't notarised.

## Verify

`SHA256SUMS` and the tag `v0.1.4` are signed with the release key in the README; each package has a GitHub build
attestation, and the Linux program and `.deb` rebuild byte for byte from the tag. See
[VERIFY.md](https://github.com/truthcoinapp/truthcoin-app/blob/v0.1.4/VERIFY.md).
